# 🔧 برومبت إنشاء مشروع "مُصحَف" من الصفر — المواصفات الكاملة

---

## 📌 وصف المشروع

أنشئ لي نظام أوتوميشن (Automation) بلغة Python يقوم بتوليد فيديوهات قرآنية احترافية جاهزة للنشر على TikTok / Instagram Reels / YouTube Shorts — بضغطة زر واحدة.

النظام يعمل محلياً على جهاز Windows ويتكون من:
1. **محرك توليد فيديو** (`generator.py`) — يحمّل التلاوة + يصمم البطاقة + يدمج بـ FFmpeg
2. **خادم محلي** (`server.py`) — Threading HTTP Server على بورت `5055`
3. **لوحة تحكم ويب** (`index.html`) — واجهة عربية RTL فخمة تعمل من المتصفح
4. **قاعدة بيانات** (`tasks.xlsx`) — ملف إكسيل فيه 556 ركوعاً يغطي المصحف كاملاً
5. **مجلد خلفيات** (`خلفيات/`) — المستخدم يضع فيه فيديوهات وصور كخلفيات

## 🔗 الـ APIs المستخدمة

### 1. تحميل صوت التلاوة (آية بآية)
```
المصدر الأول (ياسر الدوسري + 4 قراء):
https://the-quran-project.github.io/Quran-Audio/Data/{reciter_id}/{surah}_{ayah}.mp3

المصدر الثاني (15 قارئاً — EveryAyah):
https://everyayah.com/data/{reciter_folder}/{surah_3digits}{ayah_3digits}.mp3
مثال: https://everyayah.com/data/Yasser_Ad-Dussary_128kbps/001001.mp3
```

### 2. جلب نصوص الآيات (رسم عثماني مع تشكيل)
```
الأساسي: https://quranapi.pages.dev/api/{surah_number}.json
البديل:  https://api.alquran.cloud/v1/surah/{surah}/quran-uthmani
```

### 3. جلب بيانات الركوعات (التقسيم الموضوعي)
```
https://api.alquran.cloud/v1/ruku/{ruku_number}
(من 1 إلى 556)
```

## 🎬 محرك التوليد (generator.py) — التفاصيل الكاملة

### خطوات التوليد لكل مقطع:

#### الخطوة 1: جلب نصوص الآيات
- يأخذ رقم السورة + من آية + إلى آية
- يجلب النصوص بالرسم العثماني مع التشكيل الكامل من API

#### الخطوة 2: تحميل الصوت
- يحمّل صوت كل آية بشكل منفصل (ملف MP3 لكل آية)
- يقيس مدة كل آية بالضبط باستخدام FFmpeg
- يدمج كل ملفات الصوت في ملف واحد (`merged_audio.mp3`)

#### الخطوة 3: معالجة الخلفية الذكية
- **إذا فيديو أطول من التلاوة:** يقصه بذكاء (`-ss` + `-t`) مع بداية عشوائية
- **إذا فيديو أقصر:** يكرره تلقائياً (`-stream_loop -1`)
- **إذا صورة:** يكبرها ويقصها لتناسب 1080×1920 مع طبقة تعتيم للقراءة
- **إذا لم توجد خلفية:** يولّد خلفية سوداء داكنة

#### الخطوة 4: تصميم بطاقات الآيات (Pre-rendering)
لكل آية يرسم بطاقة RGBA كاملة تحتوي:
- **العنوان** (أعلى): `﴿ سُورَةُ البقرة ﴾` — بخط Amiri Bold ذهبي
- **الموضوع** (تحت العنوان): عنوان المقطع الموضوعي
- **خط فاصل ذهبي**
- **نص الآية** (وسط): بالخط العثماني الأبيض مع رقم الآية `﴿٢٥٥﴾`
- **صندوق خلفية** خلف النص (زجاجي شفاف أو معتم أو بدون — حسب اختيار المستخدم)
- **بادج القارئ** (أسفل): `القارئ الشيخ ياسر الدوسري`
- **شريط تقدم ذهبي** (أسفل الشاشة): يتحرك مع التلاوة

#### الخطوة 5: رندرة الفيديو
- يرسل الإطارات frame-by-frame عبر stdin pipe إلى FFmpeg
- الدقة: **1080×1920** (عمودي 9:16)
- معدل الإطارات: **30 FPS**
- الترميز: `libx264` / `aac` / `CRF 18`
- إذا كانت الخلفية فيديو: يستخدم `-filter_complex overlay` لدمج الطبقات

#### الخطوة 6: ملف النشر
يولّد ملف `_social.txt` بجانب كل فيديو يحتوي:
```
✨ تلاوة خاشعة تريح القلوب | سورة البقرة (255-257)
🎙️ بصوت القارئ الشيخ ياسر الدوسري
📖 الموضوع: آية الكرسي وعظمة الله
🏷️ هاشتاقات: #قرآن #سورة_البقرة #ياسر_الدوسري #تلاوة_خاشعة #quran #fyp #shorts #reels
```

### معالجة النص العربي:
- مكتبة `arabic_reshaper` لإعادة تشكيل الحروف العربية
- مكتبة `python-bidi` لدعم اتجاه الكتابة RTL
- خط **Amiri Bold** (يُحمّل تلقائياً من Google Fonts إن لم يوجد)
- دعم الأرقام العربية: `﴿٢٥٥﴾` بدل `﴿255﴾`

### المكتبات المطلوبة:
```
pip install requests pillow arabic-reshaper python-bidi imageio-ffmpeg openpyxl
```

## 🎨 خيارات المونتاج (يختارها المستخدم من لوحة التحكم)

### أنيميشن ظهور الآيات (`verse_animation`):
| القيمة | الوصف |
|--------|-------|
| `instant` | الآية تظهر كاملة دفعة واحدة (الافتراضي) |
| `typewriter` | الآية تظهر وكأنها تُكتب حرفاً حرفاً |
| `fade` | الآية تبدأ شفافة وتتضح تدريجياً خلال ثانية |

### خلفية النص (`text_bg_style`):
| القيمة | الوصف |
|--------|-------|
| `glass` | صندوق زجاجي شفاف خلف النص — `fill=(0,0,0,140)` (الافتراضي) |
| `solid` | صندوق معتم داكن — `fill=(0,0,0,220)` |
| `none` | بدون صندوق — النص مباشرة على الخلفية مع ظل فقط |

## 🌐 الخادم المحلي (server.py)

- **النوع:** `ThreadingHTTPServer` (متعدد المسارات لعدم التعليق)
- **البورت:** `5055`
- **الرابط:** `http://127.0.0.1:5055`

### الـ Endpoints:

| Method | المسار | الوظيفة |
|--------|--------|---------|
| GET | `/` | يقدم ملف `index.html` |
| GET | `/api/tasks` | يعيد كل الركوعات الـ 556 كـ JSON |
| GET | `/api/reciters` | يعيد قائمة القراء الـ 15 |
| GET | `/api/backgrounds` | يعيد قائمة الخلفيات من مجلد `خلفيات/` |
| GET | `/api/status` | يعيد حالة التوليد الحالية (تقدم، سجل، أخطاء) |
| GET | `/api/outputs` | يعيد قائمة الفيديوهات المنتجة في `output/` |
| GET | `/output/{filename}` | يقدم ملف فيديو مع دعم Range headers (HTTP 206) |
| POST | `/api/start` | يبدأ توليد المقاطع المحددة في thread منفصل |
| POST | `/api/stop` | يوقف التوليد الجاري |
| POST | `/api/open_folder` | يفتح مجلد الخلفيات أو الفيديوهات على الجهاز |

### حالة التوليد (Global State):
```python
state = {
    "is_running": False,       # هل التوليد جاري؟
    "current_index": 0,        # المقطع الحالي
    "total_tasks": 0,          # إجمالي المقاطع
    "current_task_name": "",   # اسم المقطع الحالي
    "progress_percent": 0,     # نسبة التقدم الكلي
    "logs": [],                # سجل العمليات (آخر 200 سطر)
    "should_stop": False,      # هل طلب المستخدم التوقف؟
    "completed_tasks": [],     # المقاطع المكتملة
    "error_tasks": []          # المقاطع التي فشلت
}
```
- يُلف في `try...finally` لضمان إعادة `is_running = False` حتى لو حصل خطأ
- يُحدّث ملف `tasks.xlsx` بحالة كل مقطع بعد اكتماله

## 🖥️ لوحة التحكم (index.html)

### التصميم:
- **اتجاه:** RTL عربي بالكامل
- **الألوان:** Dark Lapis `#0A0F1D` + Gold `#D4AF37`
- **الخطوط:** IBM Plex Sans Arabic (واجهة) + Reem Kufi (عناوين) + Amiri (قرآني)
- **تأثيرات:** Glassmorphism، backdrop-filter، hover animations، pulse dots

### الأقسام:
1. **الهيدر:** شعار "ق" ذهبي + اسم المشروع + بادج حالة المحرك
2. **إحصائيات:** 4 بطاقات (عدد المقاطع، القارئ، الخلفيات، الفيديوهات المنتجة)
3. **إعدادات التوليد:**
   - اختيار القارئ (15 قارئاً)
   - نمط الخلفية (عشوائي / محدد)
   - أنيميشن الآيات (فوري / كتابة / ظهور تدريجي)
   - خلفية النص (زجاجية / معتمة / بدون)
   - أزرار فتح مجلد الخلفيات والفيديوهات
4. **التوليد الحر:** اختيار سورة + من آية + إلى آية + عنوان مخصص
5. **جدول المقاطع:** 556 صف مع checkboxes + أزرار تحديد سريع
6. **شريط التنفيذ المباشر:** زر بدء/إيقاف + شريط تقدم + نسبة مئوية + سجل مباشر
7. **معرض الفيديوهات:** عرض الفيديوهات المنتجة مع أزرار نسخ الوصف وتنزيل

### الـ Polling:
- يسأل `/api/status` كل 1.8 ثانية لتحديث شريط التقدم والسجل
- فيديوهات المعرض تستخدم `preload="none"` لمنع التعليق
