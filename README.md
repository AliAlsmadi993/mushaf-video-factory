# مُصحَف — مصنع الفيديو القرآني

مشروع محلي بلغة Python لإنشاء مقاطع قرآنية عمودية جاهزة للنشر على TikTok وInstagram Reels وYouTube Shorts. يتضمن المشروع لوحة تحكم عربية باتجاه RTL، ومحرك توليد يعتمد على FFmpeg، وملف Excel المرفق الذي يحتوي على **556 ركوعًا**.

> **مهم:** هذا المشروع يعمل محليًا على جهازك. لا تُرفع التلاوات أو الفيديوهات إلى خادم خارجي؛ الاتصال بالإنترنت يُستخدم فقط لجلب نصوص الآيات والملفات الصوتية عند الحاجة، وتُحفظ الملفات المؤقتة داخل مجلد `temp`.

## مكونات المشروع

| الملف أو المجلد | الوظيفة |
|---|---|
| `server.py` | خادم لوحة التحكم على `http://127.0.0.1:5055`. |
| `generator.py` | محرك جلب النص والصوت، وتجهيز البطاقة، وتركيب الفيديو. |
| `index.html` | واجهة عربية RTL لاختيار الركوعات والإعدادات ومتابعة التنفيذ. |
| `tasks.xlsx` | قاعدة البيانات المرفقة للركوعات. |
| `build_full_quran_rukus.py` | تصدير Excel إلى `tasks_raw.json` وتحديث مخزن نصوص السور اختياريًا. |
| `خلفيات/` | ضع فيه صورًا أو فيديوهاتك الخلفية. |
| `output/` | الفيديوهات النهائية وملفات الأوصاف الاجتماعية. |
| `temp/` | الصوتيات والنصوص والبطاقات المؤقتة المعاد استخدامها لتسريع التوليد. |
| `install_windows.bat` | تثبيت مكتبات Python وتجهيز المجلدات. |
| `تشغيل_لوحة_التحكم.bat` | تشغيل الخادم وفتح لوحة التحكم بنقرة مزدوجة. |

## التشغيل على Windows

ثبّت Python 3.10 أو أحدث، ثم افتح المجلد واضغط مرتين على `install_windows.bat`. بعد انتهاء التثبيت ضع الخلفيات داخل مجلد `خلفيات`، ثم شغّل `تشغيل_لوحة_التحكم.bat`. ستفتح الواجهة تلقائيًا على العنوان المحلي:

`http://127.0.0.1:5055`

لإيقاف الخادم اضغط `Ctrl+C` في نافذة الخادم. زر **إيقاف آمن** داخل الواجهة يوقف عملية التوليد الحالية بعد إنهاء الجزء الجاري بدلًا من قطع ملف الفيديو في منتصفه.

## اختبار سريع بدون إنترنت

للتأكد من أن Python وPillow وFFmpeg يعملون على جهازك، نفّذ:

```bash
python generator.py --demo --output output/demo.mp4
```

ينشئ الأمر فيديو اختبار مدته قصيرة في مجلد `output`. هذا الاختبار لا يحتاج إلى API أو تلاوة حقيقية.

## التشغيل على Linux أو macOS

نفّذ الأوامر الآتية من داخل المجلد:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 build_full_quran_rukus.py
python3 server.py
```

ثم افتح `http://127.0.0.1:5055` في المتصفح.

## سير العمل داخل الواجهة

اختر قارئًا وخلفية، ثم حدد ركوعًا أو عدة ركوعات من الجدول. يمكنك استخدام البحث والتحديد السريع، ثم اختيار نمط ظهور الآيات وخلفية النص. اضغط **بدء التوليد**. يُعرض تقدم العملية وسجلها مباشرة، ويُحفظ لكل فيديو ملف `_social.txt` بجانب ملف MP4.

يمكن تفعيل قسم **التوليد الحر** لإضافة سورة ورقم بداية ونهاية الآيات إلى التحديد الحالي. يجب أن تتأكد من صحة نطاق الآيات المدخل؛ نصوص الآيات تُجلب من المصادر العامة المحددة في المحرك.

## مصادر البيانات ودقة النص

يقرأ المحرك نص الآيات من المصفوفة `arabic1` التي ترجعها استجابة `quranapi.pages.dev` مباشرة، ولا يكتب آيات ثابتة داخل الكود ولا يعيد بناء النص من ملف Excel. يُستخدم مصدر Al Quran Cloud كبديل فقط إذا تعذر الوصول إلى المصدر الأساسي.[1] [2] [3] يحتفظ البرنامج بالنص الخام في مخزن السورة، ويطبق معالجة اتجاه RTL على طبقة الرسم فقط عند الحاجة التقنية؛ لا يتم تبديل حروف الآية أو استبدالها بنص قالب.

يستخدم الرندر `AmiriQuran.ttf` مع دعم Pillow/libraqm عندما يكون متاحًا، ويستخدم `Amiri-Bold.ttf` كحل احتياطي آمن على البيئات التي لا توفر دعم RTL الأصلي، حتى لا تظهر مربعات أو رموز ناقصة.

## ملاحظات أداء وجودة

المخرج العمودي بدقة 1080×1920 وبمعدل 30 إطارًا في الثانية، مع ترميز H.264 وصوت AAC. عند تكرار توليد نفس الآيات والقارئ، يعاد استخدام الملفات الموجودة في `temp/audio` بدل تنزيلها من جديد. لذلك يُستحسن الاحتفاظ بمجلد `temp` بين عمليات التشغيل.

توجد المعالجة الخلفية تلقائيًا: الصورة تُمدد وتُقص لتناسب 9:16، والفيديو القصير يُكرر، والفيديو الأطول يُقص حسب مدة التلاوة. إذا لم توجد خلفية، يستخدم المحرك خلفية داكنة مولدة تلقائيًا.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| لا تفتح الواجهة | تأكد من تشغيل `server.py` أو `تشغيل_لوحة_التحكم.bat` وعدم حجز المنفذ 5055. |
| فشل تنزيل الصوت | تحقق من الاتصال بالإنترنت، ثم أعد المحاولة؛ قد يتأخر أحد المصادر العامة أو يرفض الطلب مؤقتًا. |
| FFmpeg غير موجود | شغّل `install_windows.bat` أو ثبّت FFmpeg وأضفه إلى PATH. المحرك يستخدم `imageio-ffmpeg` كبديل عند توفره. |
| النص العربي غير متصل | تأكد من تثبيت `arabic-reshaper` و`python-bidi` ومن وجود خط داخل `fonts/`. |
| التوليد بطيء | اختر عددًا محدودًا من الركوعات أولًا، واحتفظ بملفات الصوت المؤقتة، واستخدم خلفية فيديو بدقة مناسبة. |

## الترخيص والاستخدام

هذا القالب البرمجي لا يضم ملفات تلاوة أو خلفيات. قبل النشر التجاري أو إعادة التوزيع، راجع شروط استخدام مصادر الصوت والخلفيات التي تختارها، واحتفظ بنسبة المصدر عند اشتراطها.
